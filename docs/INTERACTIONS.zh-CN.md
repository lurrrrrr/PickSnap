# PickSnap 交互说明

PickSnap 只有一个版本。界面不区分“便携版”或“安装版”。

## 首次使用的默认状态

以下是没有旧数据时的默认值。升级会保留你已有的选择，不会重置为这张表。

| 项目 | 默认状态 |
| --- | --- |
| 收集图片 | 开启，系统截图和复制的图片自动上绳 |
| 收集文字 | 关闭 |
| 自动清理 7 天前的旧图 | 开启 |
| 鼠标移到顶部时展开 | 开启 |
| 顶部触发范围、停留时间 | 整个顶边，450 毫秒 |
| 悬停放大预览 | 开启 |
| 显示屏幕 | 跟随鼠标 |
| 开机启动 | 默认不启用；已有 Windows 启动项按原设置保留 |
| 外观 | 经典绳子主题，配色跟随系统 |
| 显示／收起绳子 | Ctrl+Alt+T |
| 区域截图 | Ctrl+Alt+S |

设置修改成功后立即保存，退出、重启电脑和更新后都会保留。卸载选择“保留数据”后，通过 Install.cmd 重新安装会恢复图片、文字和设置；选择删除数据后，重新安装使用默认值。开机启动属于 Windows 启动项，卸载会移除，重新安装后需要按需开启。

## 收集和上绳

| 操作 | 什么时候发生 | 结果 |
| --- | --- | --- |
| 收集图片 | 开启后，系统截图文件夹产生新图片，或你复制一张图片 | 自动收集并挂上绳子，两种来源由同一个开关控制 |
| 收集文字 | 开启后，你复制文字 | 放进文字信封，最多保留最近 100 条 |
| 添加图片 | 从托盘选择本地图片 | 立即收进 PickSnap 并上绳，关闭收集图片后仍可使用 |
| 区域截图 | 主动选择屏幕上的区域 | 保存截图并上绳，关闭收集图片后仍可使用 |
| 放进篮子 | 从绳子上取下图片 | 图片留在待挂区，文件仍保留，可以再次挂上 |
| 挂上绳子 | 在待挂区选图后点击 | 按剩余位置挂上，挂不下的仍留在待挂区并保持选中 |
| 贴图 | 点开夹子，让图片留在桌面 | 图片成为独立浮窗；关闭贴图时挂回绳子，不删除图片 |
| 删除所选 | 在篮子中选图并删除 | 将 PickSnap 保存的图片移入回收站，同时从绳子和篮子移除 |

绳子满时，新图仍可收进篮子。自动上绳会将较早的挂图放回篮子；篮子中手动挂图则只使用空位，避免挤掉已有挂图。

关闭“收集图片”会收起绳子上的图片篮子，关闭“收集文字”会收起文字信封，已保存的内容不删除。随时可从托盘打开它们。空信封从托盘打开时只提示一句，不弹空白面板；关闭文字收集并清空后，面板会自动收起，刚删除时会留出约 5 秒供撤销。

## 截图与编辑

PrtSc 和 Win+Shift+S 在调用 Windows 截图工具时走同一套处理（需开启“收集图片”）：

1. 先收集新截图。系统先保存文件、后写入剪贴板时，会尝试关联、去重。
2. 在截图工具中编辑后，只有新的图像写入剪贴板，PickSnap 才能读取编辑结果。点击“复制”是明确的触发方式；如果截图工具自动写入了编辑结果，也会触发，不要求一定手动点击“复制”。如果修改只留在编辑窗口里，没有写入剪贴板，等待不会更新卡片。
3. 收到剪贴板变化后约 600 毫秒读取图像，尝试关联到近期截图。关联成功后暂存编辑结果，约 3 秒后更新原卡片；期间收到新的可关联编辑图像，会重新计时。这里不是判断“编辑已经完成”，也不是等待所有类型的剪贴板内容静止。
4. 更新保留卡片的位置和贴图状态，不为每笔标注增加一张图。超过等待时间后继续编辑并复制，仍可再次更新；无法确认关联的图像会作为新图收集。

Windows 没有在剪贴板中提供可靠的截图编辑会话标识，因此这里结合截图工具来源、近期图片、尺寸和画面相似程度识别。间隔超过 10 分钟，或裁剪、改动过大无法确认关联时，会保留为新图，以免覆盖另一张图。普通软件复制的图片仍作为新图收集。单独按下只复制全屏的旧式 PrtSc，其后在其他编辑软件中的操作不视为 Windows 截图工具的同一编辑会话。

PickSnap 自带“区域截图”会同时覆盖已连接的显示器。把鼠标移到目标屏幕后拖选即可，不需要先改设置中的“显示屏幕”。这项设置只决定绳子的显示位置。开始在另一屏选择会放弃前一屏的选区；完成只导出当前选区，Esc 取消会收起全部屏幕的截图界面。目前选区在一块屏幕内，不跨屏拼接。

## 文字删除与撤销

单击文字条目的正文、时间或空白区域即可选中，再单击一次取消选中。只有在被截断的长文正文上、260 毫秒内完成双击才打开全文；短文字、时间和空白区域的连续点击只切换选中。左侧圆圈始终只用于勾选。移除了单独的“读”按钮，右侧仅保留复制和删除，独立操作、不改变选中状态。整行高亮与勾选保持一致。

“删除所选”先确认，再删除选中的文字。左上角撤销按钮每次恢复一条，旁边下拉菜单可选择“撤销本批删除”，重做按钮可再次删除刚恢复的内容。支持 Ctrl+Z / Ctrl+Y。恢复时保持原顺序，也保留期间新收集的文字。

撤销记录保留到本次文字面板关闭，最多保留最近 20 批；关闭面板后不再提供这段删除历史。文字没有图片那样的回收站。

“绳上 4/24”表示已挂 4 张、最多挂 24 张；容量随显示区域变化。贴图数量单独计算。在篮子选择图片时显示“已选 N 张，绳子上还能挂 M 张”，M 表示当前可用位置，并非选中后预测的剩余位置。

## 顶部触发

开启“鼠标移到顶部时展开”后，把鼠标移到所选屏幕的顶部并停留。默认等待 450 毫秒，可在设置中调整；设置窗口打开时也能试用。

- 屏幕中段：横向 30%～70%。
- 偏左区域：横向 8%～40%。
- 整个顶边：整个横向范围。为方便点击窗口关闭／最大化按钮，右上角的标题栏按钮区域会避让。

关闭这个开关后，仍可用快捷键或托盘显示绳子。真正的全屏游戏／视频期间不自动展开，普通最大化窗口仍可触发。固定了显示屏幕时，需在那块屏幕上触发。

## 七天清理

开启后立即检查一次，以后每次启动和每六小时检查一次。PickSnap 保存的图片超过七天未修改，会移入回收站，并从绳子、贴图与篮子中移除。这个开关不清理文字。

图片篮子顶部与设置中的“自动清理 7 天前的旧图”是同一个开关，改一处即可。开启会立即按上述规则清理，并非从开启之日起再等七天。

现在新添加或收集的图片统一保存到 PickSnap 的收集文件夹，清理的就是这里的图片。系统截图文件夹、聊天软件等位置原本保存的文件不属于 PickSnap 的清理范围。

旧版本留下的部分记录直接指向外部文件。为避免删掉其他文件夹中的文件，这些过期记录仅从 PickSnap 清单移除。此前“原始图片不受影响”指的是这种来源文件与收集副本的区别，不是另一种图片功能。

## 更新和卸载

“检查更新”只查询版本并显示结果，不会下载或重启。发现新版后查看说明，点击“更新并重启”才会下载；校验完成自动安装并重新打开，图片、文字和设置保留。更新前会检查未保存的编辑，下载可以取消。

正常启动约 15 秒后会自动检查，持续运行时每 12 小时再检查。发现未提醒过的新版本时显示 Windows 托盘通知，点击可查看更新；同一个版本只自动提醒一次，选择“跳过此版本”后也不会反复提醒。Windows 关闭通知或开启免打扰时可能看不到通知，但仍可在设置中检查。后台检查失败不会反复弹窗，手动检查会在页面显示失败原因。

卸载默认保留图片、文字和设置，可在确认页改为删除；删除还需勾选确认，取消则不卸载。数据保存位置直接显示在确认页，下次通过 Install.cmd 安装后自动恢复。

程序放在标准应用目录时，会自动移除程序文件；直接在自己选择的文件夹中运行时，完成数据处理后按提示删除该文件夹。这是文件所在位置的处理差异，使用的仍是同一个 PickSnap。

## 菜单关闭与键盘操作

托盘和图片右键菜单在鼠标离开约 450 毫秒后收起，刚打开时给鼠标进入菜单留出约 1.2 秒。移动到子菜单仍算在菜单内；点击外部、切换前台窗口或打开另一个菜单会关闭旧菜单。键盘导航期间不因为鼠标停在外面而关闭，Esc 可收起。子菜单动作先关闭子菜单，再关闭主菜单，避免悬空弹层。

文字面板的“单击选择，双击阅读全文”固定在标题栏，位于撤销区与关闭按钮之间。复制／删除等操作反馈显示在底部，不遮挡条目。
